## Plan 02-01: Core Streaming Types — SessionEvent, PartiallyGenerated, GenerationSchema, RuntimeGenerationChannel

Define the four foundational streaming types for the Phase 2 runtime: the provider-agnostic event model, the structured output snapshot system, runtime JSON schema generation from Codable types, and the concrete channel that bridges executor output to AsyncThrowingStream consumers.

Purpose: These types are the data plane of the AgentRuntime — every event flowing through the agent loop, every structured output snapshot, and every schema used for tool inputs passes through these types. They are pure value types and actors with zero external dependencies beyond Phase 1 protocols and the existing JSONSchema type.

Output: 4 new Swift source files in Sources/SwiftAgentCore/AgentRuntime/ + 1 test file in Tests/SwiftAgentCoreTests/
</objective>

    A public protocol `GenerationSchema: Codable, Sendable` with one static requirement: `static var jsonSchema: JSONSchema { get }`. JSONSchema is the existing type from Types/Tool.swift.

    Protocol extension provides a default implementation calling `generationSchemaFromMirror(Self.self)`.

    A public top-level function `generationSchemaFromMirror(_ type: Any.Type) -> JSONSchema`:
    1. Attempt to create a sample instance of the type (all-zero/nil/empty defaults) via Mirror or a zero-init approach. If creation fails, return JSONSchema(type: "object", description: "Schema unavailable").
    2. Use Mirror(reflecting: sample) to iterate children.
    3. For each child with a non-nil label:
       - Extract the type string via String(describing: type(of: child.value))
       - Map Swift types to JSON types via a private helper: `String -> "string"`, `Int|Int32|Int64|Double|Float -> "number"`, `Bool -> "boolean"`, default -> "string"`
       - For Optional types (prefix "Optional<"): unwrap inner type, do NOT add to required
       - For non-Optional types: add label to required array
       - Create JSONSchemaProperty(type: jsonType) for each
    4. Return JSONSchema(type: "object", properties: propertiesDict, required: requiredArray)

    Private helper `mapSwiftToJSONType(_ swiftType: String) -> String` handles the mapping and Optional unwrapping. Private helper `createSampleInstance(_ type: Any.Type) -> Any?` creates a sample using a best-effort approach (try default init via protocol, or return nil).

    IMPORTANT: The function creates a sample instance via `(type as? AnyClass.Type)` or similar. Since Swift does not support `type.init()` without a protocol, use a pragmatic approach: for types that conform to a helper protocol `DefaultInitializable` (define inline: `protocol DefaultInitializable { init() }`), create the sample via that. For types that don't, return a best-effort schema with just `type: "object"` and a description note. Define this helper protocol as internal to GenerationSchema.swift (not public).
  </action>

    Create TWO files:

    FILE 1: Sources/SwiftAgentCore/AgentRuntime/RuntimeGenerationChannel.swift

    A public actor `RuntimeGenerationChannel` conforming to `GenerationChannel`. This is the concrete implementation behind the GenerationChannel protocol. It bridges the executor's output to the AsyncThrowingStream's continuation by yielding SessionEvent values.

    Internal state:
    - private var continuation: AsyncThrowingStream<SessionEvent, Error>.Continuation? — set via setContinuation(_:)
    - private var isFinished: Bool = false — guards against post-completion sends (Pitfall 3: dangling events after turnComplete)
    - private var accumulatedText: String = "" — accumulated text for snapshot semantics
    - private var accumulatedThinking: String = "" — accumulated thinking for snapshot semantics

    Methods (all implement GenerationChannel protocol):
    - func setContinuation(_ c: AsyncThrowingStream<SessionEvent, Error>.Continuation) — stores the continuation for later yields
    - func send(textDelta: String) async — replaces accumulatedText with textDelta (snapshot, not append!), guards isFinished, yields .textDelta(accumulatedText)
    - func send(thinkingDelta: String) async — replaces accumulatedThinking with thinkingDelta, guards isFinished, yields .thinkingDelta(accumulatedThinking)
    - func send(toolCallRequest id: String, name: String, input: Data) async — guards isFinished, yields .toolCallRequested(id:name:input:)
    - func send(toolCallCompleted id: String, output: ToolOutputValue) async — guards isFinished, yields .toolCallCompleted(id:output:isError:false)
    - func complete(stopReason: String?, usage: Usage?) async — guards isFinished, sets isFinished=true, yields .turnCompleted(usage:stopReason:), then calls continuation?.finish()
    - func fail(with error: AgentRuntimeError) async — guards isFinished, sets isFinished=true, yields .error(error), then calls continuation?.finish(throwing: error)

    KEY BEHAVIOR: Every method checks `guard !isFinished else { return }` at the top. After complete() or fail(), all subsequent calls are silently dropped. This prevents the "dangling event after turn complete" pitfall (PITFALLS.md Pitfall 3).

    NOTE: textDelta signal uses REPLACEMENT semantics (accumulatedText = textDelta), not APPEND semantics. The executor provides accumulated total text, not incremental deltas. This is the snapshot model — each .textDelta event carries the complete text so far.
