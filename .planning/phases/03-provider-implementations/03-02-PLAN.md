<objective>
Implement the DeepSeekProvider — a single LanguageModel + LanguageModelExecutor struct that handles both DeepSeek's Anthropic-compat endpoint (`/anthropic/v1/messages`) and OpenAI-compat endpoint (`/v1/chat/completions`) through an internal `APICompatibility` switch. Both paths produce identical `SessionEvent` output for equivalent inputs. This unifies the existing dual code paths (App/LLM/DeepSeekProvider wrapping LLMClient + App/DeepSeek/DeepSeekClient for OpenAI-compat) into a single Core provider.

Purpose: Eliminate the dual-code-path maintenance burden. The existing production system uses two separate clients for the same provider depending on which endpoint is configured — this plan folds them into one provider behind a single protocol conformance.
Output: Five new source files under `Providers/DeepSeek/` plus a test file. Zero modifications to existing files.
</objective>

      - .instruction(String) → `{role: "system", content: String}`
      - .prompt(String) → `{role: "user", content: String}`
      - .response(String) → `{role: "assistant", content: String}`
      - .toolCall(id, name, input) → `{role: "assistant", tool_calls: [{id, type: "function", function: {name, arguments: JSONString}}]}`
      - .toolOutput(id, output, isError) → `{role: "tool", tool_call_id: id, content: output}`
      - .thinking(String) → `{role: "assistant", content: "[Thinking] \(text)"}` (DeepSeek doesn't natively store thinking in messages)
      - .system(String) → `{role: "user", content: "[System] \(text)"}`

    **File 5: DeepSeekSSEParser.swift** — `actor DeepSeekSSEParser` (internal)

    - OpenAICompat mode:
      - SSE line: `data: {"id":"...","choices":[{"index":0,"delta":{"content":"Hello"}}]}`
        → accumulate text + emit textDelta snapshot
      - SSE line: `data: {"choices":[{"index":0,"delta":{"reasoning_content":"..."}}]}`
        → accumulate thinking + emit thinkingDelta snapshot (R1 models only)
      - SSE line: `data: {"choices":[{"index":0,"delta":{"tool_calls":[{"index":0,"id":"call_1","function":{"name":"Bash","arguments":"{\"cmd\":\"ls\"}"}}]}}]}`

        → emit turnCompleted with stopReason "end_turn"
      - SSE line: `data: [DONE]` → stream ends
    - Snapshot semantics REQUIRED: accumulate text/thinking internally, send FULL accumulated string each time
