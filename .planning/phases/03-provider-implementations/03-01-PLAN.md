    **File 4: AnthropicSSEParser.swift** — internal class or actor that accepts `URLSession.AsyncBytes.lines` and a `GenerationChannel`, parses SSE events, and emits SessionEvent values.

    Key design decisions per RESEARCH.md Pitfall 2 (Snapshot Semantics):
    - Maintain `private var accumulatedText: String = ""` and `private var accumulatedThinking: String = ""` internally
    - On each text delta, APPEND the new token to accumulatedText, then call `await channel.send(textDelta: accumulatedText)` with the FULL accumulated string
    - Same pattern for thinkingDelta
    - Never send raw delta strings — always the complete accumulated value

    SSE event dispatch (extracted from LLMClient.streamRequest() lines 400-700):
    - `data:` prefix detection: skip lines without `data: ` prefix
    - JSON parse each data line
    - Switch on `json["type"]`:
      - "content_block_start" with content_block.type "tool_use": register tool start (id, name). Do NOT emit yet.
      - "content_block_delta" with delta.type "text_delta": accumulate text → send textDelta snapshot
      - "content_block_delta" with delta.type "thinking_delta": accumulate thinking → send thinkingDelta snapshot
      - "content_block_delta" with delta.type "input_json_delta": accumulate per-index partial_json using ContentAccumulator
      - "content_block_stop": if tool was in progress, parse accumulated JSON via safeParseJSON → emit toolCallRequested with complete input
      - "message_delta": extract stop_reason and usage → call channel.complete(stopReason:stopReason, usage:parsedUsage)
      - "message_stop": stream ends naturally (loop exits)
      - "error": extract error message → channel.fail(with: .serverError(statusCode:0, body:msg))
      - Unknown types: silently ignore (defense in depth per security domain)

| T-03-06 | Denial of Service | AnthropicSSEParser | mitigate | Malformed JSON that crashes parsing is caught by `try?` — parser continues to next line. No unchecked force-unwrap in SSE event dispatch. |
