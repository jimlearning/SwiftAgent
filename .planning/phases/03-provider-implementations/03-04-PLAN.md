    `actor SQLiteMemoryStore: RuntimeMemoryStore` — Actor-based to serialize all database access through a single thread (SQLite3 in serialized mode).

    Private state:
    - `private var db: OpaquePointer?` — SQLite3 database handle (nil if closed or failed to open)
    - `private let dbPath: String` — file path to the .db file

    Initialization:
    - `public init(location: String? = nil) throws`
    - Default location: `~/.swift-agent/memory.db` (expanded from `FileManager.default.homeDirectoryForCurrentUser`)
    - Open database with `sqlite3_open_v2(path, &db, SQLITE_OPEN_READWRITE | SQLITE_OPEN_CREATE, nil)`
    - Set pragmas: `PRAGMA journal_mode=WAL` (write-ahead logging for concurrent reads), `PRAGMA foreign_keys=ON`
    - Call `try migrateIfNeeded()` after opening

    Schema migration (RESEARCH.md Pattern 5):
    - `private func migrateIfNeeded() throws`
    - Create schema_version table if not exists (migration 1)
    - Read current version: `SELECT MAX(version) FROM schema_version`
    - Define migration steps as `[(version: Int, sql: String)]`:
      - Migration 1: `CREATE TABLE IF NOT EXISTS schema_version (version INTEGER PRIMARY KEY)`
      - Migration 2: `CREATE TABLE IF NOT EXISTS memory_entries (key TEXT NOT NULL, namespace TEXT NOT NULL, value BLOB, created_at REAL NOT NULL, updated_at REAL NOT NULL, metadata TEXT DEFAULT '{}', PRIMARY KEY (key, namespace))`
      - Migration 3: `CREATE INDEX IF NOT EXISTS idx_memory_namespace ON memory_entries(namespace)`
      - Migration 4: `CREATE INDEX IF NOT EXISTS idx_memory_updated ON memory_entries(updated_at)`
    - For each migration where version > currentVersion: execute within a transaction (`BEGIN IMMEDIATE` / `COMMIT`). On error: `ROLLBACK` and throw `AgentRuntimeError.storageFull` (reuse existing error taxonomy)
    - Insert version record after each successful migration: `INSERT INTO schema_version (version) VALUES (?)`

    RuntimeMemoryStore conformance methods:

    **store<T: Codable & Sendable>(key:namespace:value:):**
    - Encode value to Data via JSONEncoder
    - Execute: `INSERT OR REPLACE INTO memory_entries (key, namespace, value, created_at, updated_at, metadata) VALUES (?, ?, ?, COALESCE((SELECT created_at FROM memory_entries WHERE key=? AND namespace=?), ?), ?, '{}')`
    - Bind: key(1), namespace(2), value BLOB(3), key(4), namespace(5), now timestamp(6), now timestamp(7)
    - On SQLite error: throw `AgentRuntimeError.storageFull`

    **retrieve<T: Codable & Sendable>(key:namespace:):**
    - Execute: `SELECT value FROM memory_entries WHERE key=? AND namespace=?`
    - Bind: key(1), namespace(2)
    - If sqlite3_step returns SQLITE_ROW: extract BLOB bytes via `sqlite3_column_blob` / `sqlite3_column_bytes`, decode via JSONDecoder
    - If SQLITE_DONE (no row): return nil
    - On decode error: throw `AgentRuntimeError.invalidResponse(reason: "Failed to decode stored value")`

    **search(query:namespace:):**
    - Execute: `SELECT key, namespace, value, created_at, updated_at, metadata FROM memory_entries WHERE namespace=? AND (key LIKE ? OR CAST(value AS TEXT) LIKE ?)`
    - Bind: namespace(1), "%query%"(2), "%query%"(3) — LIKE-based search with wildcards
    - Iterate rows with sqlite3_step, build [RuntimeMemoryEntry] array
    - Return results

    **summarize(namespace:):**
    - Execute: `SELECT COUNT(*), GROUP_CONCAT(key, ', ') FROM memory_entries WHERE namespace=?`
    - Extract count and key list
    - Return: `"namespace '<name>': <count> entries. Keys: <keyList>. Database at <dbPath>."`

    **forget(key:namespace:):**
    - Execute: `DELETE FROM memory_entries WHERE key=? AND namespace=?`
    - Bind: key(1), namespace(2)
    - No error if key doesn't exist (DELETE is idempotent)

    **listNamespaces():**
    - Execute: `SELECT DISTINCT namespace FROM memory_entries`
    - Iterate rows, collect namespace strings
    - Return [String]

    Helper methods:
    - `private func execute(_ sql: String, bindings: [SQLiteBindable] = []) throws` — prepare, bind, step, finalize
    - `private func currentSchemaVersion() throws -> Int` — query schema_version table

    SQLite3 C API usage (following Database.swift pattern):
    - All `sqlite3_prepare_v2`, `sqlite3_bind_*`, `sqlite3_step`, `sqlite3_column_*`, `sqlite3_finalize` calls wrapped in `throws`
    - Error messages from `sqlite3_errmsg(db)` included in thrown errors
    - Parameterized queries ONLY — NEVER string-interpolate user input into SQL (security domain requirement)
    - All `sqlite3_finalize` calls happen in `defer` blocks to prevent statement leaks

    Location and data format:
    - Database file: `~/.swift-agent/memory.db`
    - Value column: SQLite BLOB (binary JSON-encoded data)
    - created_at / updated_at: `TimeInterval` (seconds since 1970, SQLite REAL)
    - metadata: JSON string stored as TEXT column

    `public struct AgentPermissionBridge: RuntimePermissionEngine, Sendable`

    This is a thin adapter per RESEARCH.md Pattern 6. It wraps the existing PermissionEngine and maps AgentPermission enum cases to tool-name-based permission checks that the existing pipeline understands.

    The struct stores the wrapped PermissionEngine as `private let engine: PermissionEngine` and the PermissionMode as `private let mode: PermissionMode`. Initializer: `public init(engine: PermissionEngine, mode: PermissionMode = .default)`.

    The `public func check(_ permission: AgentPermission) async throws -> Bool` method uses an exhaustive switch over all 13 AgentPermission cases (no `default:` clause — compiler enforces exhaustiveness):

    Explicit case-to-toolName mapping table (each calls `await engine.check(toolName:input:mode:context:)` and maps `PermissionVerdict.decision` to Bool):
    - `.runCommands` → calls `engine.check(toolName: "Bash", input: [:], mode: mode, context: .default)` — returns `verdict.decision == .allow`
    - `.readFiles(let paths)` → calls `engine.check(toolName: "Read", input: ["file_path": .string(paths.joined(separator: ","))], mode: mode, context: .default)` — returns `verdict.decision == .allow`
    - `.writeFiles(let paths)` → calls `engine.check(toolName: "Write", input: ["file_path": .string(paths.joined(separator: ","))], mode: mode, context: .default)` — returns `verdict.decision == .allow`
    - `.network(let domains)` → calls `engine.check(toolName: "WebFetch", input: ["url": .string(domains.joined(separator: ","))], mode: mode, context: .default)` — returns `verdict.decision == .allow`
    - `.all` → `return true` unconditionally (no engine check needed)
    - `.default` → `return mode == .default`
    - `.plan` → `return mode == .plan`
    - `.contacts, .calendar, .location, .camera, .microphone, .delete` → grouped in a single case clause, all `return false` (deny-by-default for unestablished permissions)

    Key design decisions:
    - PermissionEngine is Sendable (struct). AgentPermissionBridge stores it as `private let` — safe.
    - Fallback for `.contacts`, `.calendar`, `.location`, `.camera`, `.microphone`, `.delete`: `return false` (deny-by-default per security domain). These permissions have no established rules in the existing PermissionEngine.
    - PermissionMode determines `.default` and `.plan` behavior — in plan mode, only plan operations are allowed.
    - ToolUseContext.default — uses the existing default context. No new context creation needed.

    PermissionEngine.check() signature (verified from Safety/PermissionEngine.swift line 25-33):
    ```
    public func check(
        toolName: String,
        input: [String: JSONValue],
        mode: PermissionMode,

    ) async -> PermissionVerdict
    ```
    Returns `PermissionVerdict` with `decision: PermissionDecision` enum (`.allow`, `.deny`, `.ask`). AgentPermissionBridge maps `.allow` → `true`, `.deny`/`.ask` → `false`.
