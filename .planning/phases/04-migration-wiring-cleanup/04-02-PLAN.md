<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tool init boundary | Context fields (workingDirectory, mcpClients) are provided by the session constructor — tools trust these values |
| Arguments decode boundary | JSON from the LLM is decoded into typed Arguments — malformed JSON causes DecodingError, not undefined behavior |
| Tool execution boundary | call(arguments:) uses self.workingDirectory for path resolution — path traversal attacks prevented by FileManager canonicalization in existing tool logic |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | Arguments decode in execute() | mitigate | JSONDecoder with Codable structs — type mismatch causes immediate DecodingError; no stringly-typed dict access |
| T-04-02 | Information Disclosure | FileReadTool, GrepTool, GlobTool | mitigate | workingDirectory restricts file access scope; existing FileManager checks preserved from old implementations |
| T-04-03 | Spoofing | Tool name collision in ToolEngine registry | mitigate | DefaultToolEngine keys by tool.name — duplicate names overwrite previous registration (last write wins) |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No external packages installed in this phase — all types are project-internal |
</threat_model>
